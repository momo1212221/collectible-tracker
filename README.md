# Collectible Tracker

Shows:
- Gold bolts collected globally (x/40)
- Remaining live gold-bolt objects in the current level
- Remaining live infobot objects
- Live skill-point trigger objects

L2 + R2 + Triangle shows the summary. It can also appear automatically after a level loads.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
